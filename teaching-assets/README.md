# Material docente

- `Clase1.pptx`: presentación de clase.
- `aulas_virtuales/`: ocho páginas HTML entregadas como apoyo en Aulas Virtuales.
- `archive/Metodos_Numericos_notas_2025.pdf`: versión histórica de 24 páginas.

La versión histórica se conserva únicamente para trazabilidad. Las notas manuscritas
vigentes de 98 páginas se distribuyen mediante Aulas Virtuales y no se versionan aquí:
su archivo fuente pesa 92,34 MiB y volvería innecesariamente pesado cada clon del
repositorio. Las páginas HTML sí forman parte de esta copia.

El acta de concertación no se copia al repositorio estudiantil para evitar redistribuir
datos personales. Sus fechas, porcentajes y modalidad se transcriben en
`../assessments/README.md`.
