## Precedencia

Cuando dos materiales difieran, se aplica este orden:

1. Acta de concertación y directrices institucionales.
2. Comunicaciones posteriores por canales institucionales.
3. Presentación general de Aulas Virtuales.
4. Documentación de este repositorio.
5. Versiones históricas archivadas.
