# Referencias y material complementario

`Gezerlis_OnlineAppD.pdf` corresponde a material complementario asociado al libro de
Alex Gezerlis. Debe conservarse su atribución y revisarse la autorización de
redistribución antes de hacer público este repositorio.

El libro completo utilizado por el profesor no se almacena en este repositorio.

Referencia principal:

Alex Gezerlis, *Numerical Methods in Physics with Python*, 2.ª edición, Cambridge
University Press, 2023. ISBN 978-1-009-30385-9.

Las soluciones que el autor marca explícitamente como desbloqueadas y disponibles para
todos los lectores se incluyen en `examples/solutions_self_study/` como material de
práctica autónoma. No se utilizan como preguntas de los parciales.
