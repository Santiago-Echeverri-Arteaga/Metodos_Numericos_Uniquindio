# Notebooks

- `Matrices.ipynb`: exploración de residuo, solución y condicionamiento.
- `MINSTEjemplo.ipynb`: red neuronal y diferenciación automática con TensorFlow.

Antes de usar un notebook como actividad estudiantil debe incluir propósito, preguntas,
instrucciones, semillas aleatorias y una ejecución limpia desde la primera celda. MNIST
requiere la dependencia opcional `ml` y descarga datos externos la primera vez.
