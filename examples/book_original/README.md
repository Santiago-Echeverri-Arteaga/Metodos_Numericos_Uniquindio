# Códigos originales del libro

Programas atribuidos a Alex Gezerlis para *Numerical Methods in Physics with Python*,
segunda edición, Cambridge University Press, 2023.

Los 63 archivos fueron restaurados desde `second_codes (1).zip`, adjuntado por el
profesor. Se conservaron sin modificaciones de contenido; las variantes locales están
en `examples/class_demos/`.

Esta carpeta se conserva como referencia y no debe utilizarse para modificaciones de
clase. Las adaptaciones deben copiarse a `examples/class_demos/` indicando el archivo de
origen y los cambios realizados.

La presencia de estos archivos en el repositorio no sustituye la revisión de sus
términos de distribución. Antes de publicar o redistribuir el repositorio, confirme la
licencia aplicable al material descargado del sitio del libro.
