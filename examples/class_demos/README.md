# Demostraciones de clase

Adaptaciones y ejemplos preparados para las sesiones del curso.

| Archivo | Tema |
|---|---|
| `suma_kahan.py` | Suma compensada de Kahan y error de redondeo |
| `large.py` | Pérdida de números pequeños |
| `finitediff.py` | Diferencias hacia adelante y central |
| `richardsondiff.py` | Extrapolación de Richardson |
| `Legendre.py` | Polinomios de Legendre |
| `Ridder.py` | Método de Ridder |
| `Broyden.py` | Método de Broyden |
| `fixedpoint_modified.py` | Variante de punto fijo empleada en clase |
| `psis_plot.py` | Adaptación de funciones de onda con visualización |
| `power_large_example.py` | Adaptación del método de potencias para una matriz mayor |

Estos programas son demostraciones, no soluciones de las evaluaciones. Toda adaptación
nueva debe incluir un bloque ejecutable protegido por `if __name__ == "__main__"` y una
prueba que exprese la propiedad numérica que se desea enseñar.
